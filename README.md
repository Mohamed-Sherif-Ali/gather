# Gather

Gather is a community events and RSVP app. People find local events, RSVP for a limited number of seats, join a waitlist when an event is full, follow hosts and get reminders. Hosts create and manage their events. The server owns seat counts and RSVP status, so an event can never be overbooked, even when many people RSVP at once or a phone retries a request. Gather starts as a Dart command-line app (`gather_cli/`) that holds the event model and the RSVP rules, and it will grow into a Flutter app for English and Arabic users.

**Status:** early development. Only the `gather_cli` command-line app exists so far.
